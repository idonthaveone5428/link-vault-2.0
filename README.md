LinkVault

A simple little place for all those links you want to come back to.

Found an interesting reel, post, or website? Just share it to LinkVault and it's saved. No more digging through DMs or browser history.

Features

- Save links directly from other apps.
- Automatically organize links by date.
- Create collections.
- Mark links as favorites.
- Search saved links.
- Clean Material 3 interface.
